Hand-traced from raw `stats.swehockey.se /Game/Events/{id}` HTML in the lake
(branch shl-data-lake @ 6b77add) BEFORE any adapter code existed (rule 2).
Selection used a dumb row-dump helper (regex over `<td class="tdOdd">` cells,

## Source conventions confirmed during tracing (each on a named game)

- Row format `[time, type, team-code, player, detail]`; sections
  `1st/2nd/3rd period`, `Overtime`, `Game Winning Shot(s)`, `Goalkeeper
  Summary`; sections and rows NEWEST-FIRST (handoff quirk confirmed).
- Title = `HOME - AWAY (H-A)` in team CODES; `<h2>` = full names. Home =
  first title code, proven league-wide: goal-row running scores `H-A`
  increment on the scorer's side with **0 failures across all 1,456 events
  pages** (scan 2026-08-06, this session), and 0 final-score mismatches
  after excluding the GWS winner (off-by-one, tolerated — 628968).
- Goal rows: `H-A (STR)` with STR ∈ EQ/PP1/PP2/SH1/SH2/PS/GWS, optional
  `ENG` flag on a second line. `(GWS)` = shootout winner, NOT a goal
  (628968). `(PS)` = penalty-shot goal, real (628999 50:01).
- GK rows: `GK In`/`GK Out` + goalie name. 00:00 GK In = starters.
  60:00 (or OT-end, 628968 65:00 / 774733 60:52) GK Out rows =
  END-OF-GAME BOOKKEEPING, never pulls (binding rule iii,
  SHL_LAKE_VERIFICATION.md). Same-second Out+In (different goalie =
  substitution 629020 56:56, 882278 07:11, 629037 22:18; same goalie =
  feed blip, e.g. 628973 59:18 outside this batch) = net never empty.
- Penalty rows: `N min` + offense + explicit `(begin - end)` window,
  including early PP-goal termination (1004308 14:50-14:55) and stacked /
  deferred starts (628964 double minor: two same-second rows with
  CONSECUTIVE windows 24:48-26:48, 26:48-28:48). N>=10 = misconduct class.
  **Offsetting/coincident penalties carry placeholder windows
  `(00:00 - )` or `(00:00 - MM:SS)` — no box time served** (628979 59:07:
  four UC rows, 2 per side; 774444 10:27+55:23 roughing pairs, 23:09
  fighting 5-min pair; league-wide scan: 1,214 of 1,218 zero-begin
  open-end rows have a same-second opposite-team penalty; the 4 unpaired
  are near-second scrum rows, see handoff). Windows can cross game end
  clamped (629011 59:52-60:00) or be degenerate on misconducts
  (774444 GM `(05:00 - 60:00)`, AoO `(60:00 - 60:00)`) — misconducts have
  no strength effect regardless.
- `TO` = timeout; `PS` row = missed penalty shot; type-less
  `Team penalty PenaltyShot` row = the awarded foul (no minutes, no box).
